# Solar Power Plant Output Prediction

This project is made for our Applied Machine Learning assignment. The main purpose of this project is to predict the AC power generated by a solar power plant using weather data.

We used Plant 1 data from the Solar Power Generation dataset. We also collected public weather data from Open-Meteo to see how prediction using public weather data compares with prediction using sensors installed at the plant.

## What we did

First, we cleaned the generation and sensor datasets and converted the timestamps into proper datetime format.

The power readings of different inverters were combined to get the total plant power at each timestamp. After that, generation data was merged with the sensor data and converted into hourly readings.

We then performed some data visualization to understand the relationship between solar power, irradiation and temperature.

For prediction, we implemented linear regression ourselves using three methods:

- Normal Equation
- Batch Gradient Descent
- Stochastic Gradient Descent (SGD)

We did not use a machine learning library such as scikit-learn for fitting the regression model.

## Features

We made two feature sets so that we could compare local sensor data with public weather data.

### Set A

Set A uses data measured at the solar plant:

- Irradiation
- Module temperature
- Ambient temperature
- Hour represented using sine
- Hour represented using cosine

### Set B

Set B uses weather data obtained from Open-Meteo:

- Shortwave radiation
- Temperature at 2 meters
- Cloud cover
- Hour represented using sine
- Hour represented using cosine

The target in both cases is AC power.

## Train and Test Data

We used a time-based split instead of randomly shuffling the data.

Training data:

`15 May 2020 - 10 June 2020`

Testing data:

`11 June 2020 - 17 June 2020`

This was done because this is time-series data and we wanted to test the model on future observations.

## Results

The following daytime RMSE values were obtained:

| Method | Set A | Set B |
|---|---:|---:|
| Normal Equation | 704.46 | 3409.50 |
| Batch Gradient Descent | 704.46 | 3409.50 |
| SGD | 924.02 | 3341.27 |

Set A performed better than Set B in our experiment.

For the Normal Equation, the difference between Set A and Set B daytime RMSE was about 2705.04.

The peak hourly AC power in our processed data was about 27325.90, so this RMSE difference was approximately 9.90% of the peak power.

This showed us that the measurements taken directly from the plant were more useful for accurate prediction than the public weather data for this dataset.

## Gradient Descent

For Batch Gradient Descent, we tested these learning rates:

- 0.00001
- 0.0001
- 0.001

The learning rate of 0.001 diverged, while 0.0001 gave better stable convergence.

The final Batch Gradient Descent result was very close to the Normal Equation result. The maximum difference between their Set A coefficients was approximately 0.000146.

For SGD, we tested:

- 0.0001
- 0.001
- 0.01

The cost was recorded after each epoch to study the convergence behavior.

## How to Run the Project

Install the required packages:

```bash
pip install numpy pandas matplotlib requests streamlit
```

Prepare Plant 1 data:

```bash
python src/prepare.py
```

Generate the EDA plots:

```bash
python src/eda.py
```

Download the Open-Meteo weather data:

```bash
python src/fetch_weather.py
```

Train and evaluate the regression models:

```bash
python src/train_eval.py
```

Finally, run the Streamlit application:

```bash
streamlit run app/app.py
```

## What we learned

This project helped us understand how linear regression works instead of only using a ready-made machine learning function.

We learned how the Normal Equation calculates the solution directly and how Batch Gradient Descent and SGD reach a solution through repeated updates.

We also saw that choosing the learning rate is important. A learning rate that is too large can make Gradient Descent diverge.

Another important observation was that the source of weather data matters. In our results, the on-site sensor data gave much better prediction accuracy than the public weather data.
